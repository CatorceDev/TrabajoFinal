# Cliente web

Interfaz de usuario construida con React, React Router y Vite para el proyecto escolar API-REST de Lonja Veracruz.

## Ejecutar

Desde esta carpeta instala las dependencias e inicia el servidor de desarrollo:

```powershell
npm install
npm run dev
```

El cliente espera que la API esté disponible en `http://localhost:2900`. Consulta el [README principal](../README.md) para configurar y ejecutar también el servidor y la base de datos.
